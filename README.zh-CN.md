# SoundSync 简体中文汉化版

基于 [sugumar247/SoundSync](https://github.com/sugumar247/SoundSync) 的 `v2.0.0` 程序源码制作，保留原项目的音频转发功能和 MIT 许可。

## 汉化内容

- 桌面主界面、深浅色主题按钮、托盘和任务栏菜单。
- 音量、延时、均衡器、设备连接类型及系统设置的操作说明。
- 运行状态、常见音频错误、自动恢复及开机启动提示。
- 手机和浏览器使用的网络收听网页及控制提示。
- 中文字体适配，以及原版更新入口的说明。

当前界面固定使用简体中文。品牌名、Windows 提供的设备名、技术单位、协议字段、快捷键及底层系统异常原文保持原样。构建标识为 `2.0.0-zh-CN.5`。

## 启动与快捷键

连接按钮下方有两个独立开关，修改后立即保存：

- **启动后自动转发**：默认开启。打开软件后，先恢复已保存的设备勾选、软件音量、均衡器和延时，再自动连接可用的非默认转发设备。没有可用的已配置目标时不自动连接，也不弹出“请选择设备”提示。关闭后需手动连接。
- **启用快捷键**：默认关闭，避免误触。开启后，窗口在前台时可按 `C` 连接或断开，按 `M` 切换转发静音。输入框、密码框和下拉选择中不会触发；Ctrl、Alt、Shift 等组合键及长按产生的重复事件也不会触发。关闭后 C/M 不执行转发操作。

顶部“开机启动”只控制登录 Windows 时是否打开软件；底部的“启动后自动转发”控制打开后是否连接，两者分别设置。旧版启动项中的 `--autoconnect` 参数不会覆盖新开关。升级默认启用自动转发，原来绑定“开机启动”的旧 `AutoConnectOnLaunch` 字段不再控制此行为。

已勾选但隐藏的设备仍会参加转发。首次配置时，请勾选目标设备并按需要调整音量，正常退出保存；下次打开即可自动连接。

## 独立软件音量

每个设备的音量区现在分为两行：

- **系统**：调节 Windows 对应设备的音量，会影响使用该设备的其他程序。
- **软件**：仅调节 SoundSync 转发到此设备的音频，范围为 0%–100%，不会修改 Windows 设备音量或静音设置。100% 保持原信号，0% 仅将这一路转发静音。

各设备的软件音量分别保存，重启、重新连接或切换主音量补偿后保留。旧配置首次使用时默认 100%。启用快捷键后，按 `M` 静音期间调整软件音量，会保持静音；再次按 `M` 后按新音量恢复。

从 `.4` 版起，软件滑块采用立方听感曲线：位置 10% 对应振幅增益 0.001（衰减 60 dB），50% 对应 0.125（约衰减 18 dB），100% 保持原信号。小音量区间更细；鼠标悬停可查看当前衰减。100% 的最大输出没有降低，不能据此保证耳机听感安全。

`.2`、`.3` 版配置继续保存相同的实际增益，升级不会因此变响。原来显示 10% 的设置在新版约显示 46%，实际输出保持不变。远程网页使用相同曲线，协议中的 `softwareVolume` 仍为线性增益。

软件音量位于均衡器和延时缓冲之后，调节时无需等待已有延时缓冲播放完，也不依赖设备驱动是否实现 Windows 音量衰减。系统默认设备直接由 Windows 播放，其软件音量控件禁用。输出使用 WASAPI 共享模式，Windows 设备音量通常也会影响最终播放；若系统滑块改变却听不出差别，请用软件滑块控制转发音量。软件不会主动补偿目标设备的系统音量。

开启“远程控制”后，也可在手机收听网页的“电脑输出设备”区域分别调整软件音量。网页自身的音量控件仍仅控制该收听设备。

## 信号表与源音量补偿

来源设备的信号表显示实际捕获电平，不根据 Windows 音量反向放大。各转发设备的信号表显示进入该路均衡器、延时和软件音量处理前的电平；软件音量为 0 时，仍可看到是否有信号进入。

原“独立音量”按钮更名为“源音量补偿”，它控制声音增益。部分虚拟设备的回环捕获不随设备音量衰减；如果出现“系统音量越小，声音反而越大”，请关闭源音量补偿，改用各路“软件”滑块调节。

旧版本关闭声音补偿后，信号表仍会按来源设备音量添加显示补偿，造成低系统音量下信号条异常增强。本版已移除这条显示路径；源码测试使用固定采样数据模拟系统音量从 100% 降到 39% 的情形。此修复不代表已在真实 UU 驱动上完成捕获测量。

## 使用方法

1. 运行编译输出中的 `SoundSync.exe`。Windows x64 自包含构建无需另外安装 .NET 运行时。
2. Windows 默认输出设备会自动作为音频来源。勾选需要同时播放的其他输出设备。
3. 点击“连接并开始音频转发”。使用设备行中的“软件”滑块调整此路音量。再次点击连接按钮可断开；开启底部“启用快捷键”后，窗口位于前台时也可按 `C` 切换连接，按 `M` 切换转发静音。保留“启动后自动转发”开启，下次启动将按已保存的设备配置连接。
4. 如需手机收听，在同一局域网中打开程序显示的完整收听链接，并点击网页上的“连接并收听”。

程序沿用原版的 `%LOCALAPPDATA%\SoundSync` 配置。请先退出原版再运行中文版，避免两个实例争用音频或网络端口。回退时退出中文版，再运行原版即可。

“下载原版更新”会打开上游发布页，下载内容可能不包含本汉化。

## 从源码编译

需要 Windows 和 .NET 10 SDK。在仓库根目录运行：

```powershell
dotnet publish SoundSync/SoundSync.csproj -c Release -o publish -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None -p:DebugSymbols=false
```

产物位于 `publish/SoundSync.exe`，为 Windows x64 自包含单文件程序。
